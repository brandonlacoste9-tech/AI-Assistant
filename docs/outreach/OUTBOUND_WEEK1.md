## Cadence rules

1. **Max 3 emails** per prospect (Day 0 / 4 / 10).  
2. **One channel at a time** — if they reply on IG, stop email.  
3. **If “non”** — mark `lost`, never re-pitch for 6 months.  
4. **If “intéressé”** — book 15-min demo same week; send justbookme.ca/signup link.  
5. **No price wars** — one recovered booking/week pays for it.
